USB Serial Communication Protocol Specification for BeeDrive 5.0.1

BeeDrive 5.0.1 USB 串口通信协议规范

This document outlines the byte-level interface rules required to communicate with the motor controller hardware over a USB serial connection. Once the device is plugged in, it should appear as a serial peripheral. The Baudrate is 115200.

本文档概述了通过 USB 串口连接与电机控制器硬件进行通信所需的字节级接口规则。设备插入后，应显示为串口外设。波特率为 115200。

1. Frame Architecture 1. 数据帧架构

All inbound and outbound packets follow a strict framing pattern. Multibyte numeric values (such as 16-bit integers and 32-bit floats) use Little-Endian format (least significant byte first).

所有输入和输出数据包都遵循严格的帧结构。多字节数值（如 16 位整数和 32 位浮点数）使用 小端序（Little-Endian） 格式（低字节在前）。

Checksum Logic 校验和逻辑

The checksum is compiled by running an XOR (^) calculation across all sequential bytes starting immediately after the Start Byte up to, but excluding, the Checksum byte itself.

校验和是通过对从 起始字节之后 开始到 校验和字节之前 的所有连续字节进行异或（XOR，^）计算得出的。

2. Outbound Frame Profiles (Control panel → Device) 2. 输出数据帧配置（控制面板 → 设备）

Ensure byte arrays exactly match the targeted sizes. Out-of-bounds parameters will automatically be clamped internally by the motor firmware.

请确保字节数组的大小与指定尺寸完全一致。超出范围的参数将在电机固件内部被自动限制在安全范围内。

2.1 Base Resistance (Command ID: 0x00) 2.1 基础阻力 (Command ID: 0x00)

Total Frame Size: 9 Bytes 数据帧总大小: 9 字节
  • Bytes 2–3: int16 | Concentric Force limit (in decinewtons, 0.1N). Must be ≥ 0 & ≤ 8000. Bytes 2–3: int16 | 向心力限制（单位：角牛顿，0.1N）。必须 ≥ 0 且 ≤ 8000。
  • Bytes 4–5: int16 | Eccentric Force limit (in decinewtons, 0.1N). Must be ≥ 0 & ≤ 8000. Bytes 4–5: int16 | 离心力限制（单位：角牛顿，0.1N）。必须 ≥ 0 且 ≤ 8000。
  • Byte 6: uint8 | SSR Flag. Set to 0xFF for True, 0x00 for False. Byte 6: uint8 | SSR 标志。0xFF 表示开启，0x00 表示关闭。

2.2 Spring Simulation (Command ID: 0x01) 2.2 弹簧模拟 (Command ID: 0x01)

Total Frame Size: 8 Bytes 数据帧总大小: 8 字节
  • Bytes 2–3: int16 | Target extension spring path length (in mm). Must be ≥ 0. If the length is too small, the feeling will be very bad. Bytes 2–3: int16 | 目标弹簧拉伸行程长度（单位：mm）。必须 ≥ 0。如果长度设定太小，力感体验会非常差。
  • Bytes 4–5: int16 | Max peak force generated at full extension (in 0.1N). Must be ≥ 0 & ≤ 8000. Bytes 4–5: int16 | 完全拉伸时产生的最大峰值力（单位：0.1N）。必须 ≥ 0 且 ≤ 8000。

2.3 Progressive Resistance Band (Command ID: 0x14) 2.3 渐进式阻力带模拟 (Command ID: 0x14)

Total Frame Size: 11 Bytes 数据帧总大小: 11 字节
  • Bytes 2–3: int16 | Slack / Rest physical length of the band (in mm). Must be ≥ 0. Bytes 2–3: int16 | 阻力带的初始松弛/静止物理长度（单位：mm）。必须 ≥ 0。
  • Bytes 4–5: int16 | Maximum safe extension length boundary (in mm). Must be ≥ Rest length. Bytes 4–5: int16 | 最大安全拉伸长度边界（单位：mm）。必须 ≥ 静止长度。
  • Bytes 6–7: int16 | Max structural peak force at full extension (in 0.1N). Must be ≥ 0 & ≤ 8000. Bytes 6–7: int16 | 完全拉伸时的最大结构峰值力（单位：0.1N）。必须 ≥ 0 且 ≤ 8000。
  • Byte 8: uint8 | Curve non-linearity factor coefficient. Valid values: 0 to 4. Byte 8: uint8 | 曲线非线性系数。有效取值范围：0 到 4。

2.4 Isokinetic Limit (Command ID: 0x11) 2.4 等速限制 (Command ID: 0x11)

Total Frame Size: 8 Bytes 数据帧总大小: 8 字节
  • Bytes 2–3: int16 | Velocity target (in mm/s). Must be ≥ 0. The force will start increasing after this speed, following a slope defined by the parameter "Slope". Bytes 2–3: int16 | 目标速度（单位：mm/s）。必须 ≥ 0。超过此速度后阻力将开始增加，增加规律遵循由“Slope”参数定义的斜率。
  • Bytes 4–5: int16 | Slope parameter (in 0.1N/(m/s)). Must be ≥ 0 & ≤ 4000. Bytes 4–5: int16 | 斜率参数（单位：0.1N/(m/s)）。必须 ≥ 0 且 ≤ 4000。

2.5 Vibrations (Command ID: 0x04) 2.5 震动配置 (Command ID: 0x04)

Total Frame Size: 8 Bytes 数据帧总大小: 8 字节
  • Bytes 2–3: int16 | Vibration force amplitude factor (in 0.1N). Bytes 2–3: int16 | 震动力幅值参数（单位：0.1N）。
  • Bytes 4–5: int16 | Targeted mechanical cycling frequency (in Hz). Bytes 4–5: int16 | 目标机械循环频率（单位：Hz）。

2.6 System Breakout Inertia (Command ID: 0x15) 2.6 系统启动惯性阻力 (Command ID: 0x15)

Total Frame Size: 6 Bytes 数据帧总大小: 6 字节
  • Bytes 2–3: int16 | Starting static breakthrough force resistance limit (in 0.1N). Must be ≥ 0 & ≤ 8000. Bytes 2–3: int16 | 初始静态突破力阻力限制（单位：0.1N）。必须 ≥ 0 且 ≤ 8000。

2.7 Telemetry Stream Request (Command ID: 0x0E) 2.7 遥测数据流请求 (Command ID: 0x0E)

Total Frame Size: 4 Bytes 数据帧总大小: 4 字节

Polling payload to command an immediate backplane telemetry message refresh.

用于触发下位机立即回复当前传感器遥测数据的轮询指令包。

Fixed Byte Array String: 固定字节数组字符串: [0x02, 0x0E, 0x0E, 0x03]

3. Inbound Telemetry Packet (Device → Control Panel) 3. 输入遥测数据包（设备 → Control Panel）

Upon verifying a polling request, the device returns a fixed 21-byte binary status frame mapping the internal sensor matrices.

验证轮询请求后，设备会立即返回一个固定的 21字节 二进制状态帧，映射内部传感器数据矩阵。
